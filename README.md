## LITERALURA - SISTEMA DE GESTIÓN DE LIBROS Y AUTORES

### Descripción del Proyecto:

##### LiterAlura es una aplicación de consola desarrollada en Java con Spring Boot que permite a los usuarios buscar y almacenar información sobre libros y autores, extraídas de una API.

### Funcionalidades:
- Búsqueda de libros por título.
- Listado de libros registrados.
- Listado de autores registrados.
- Consulta de autores vivos en un año específico.
- Listado de libros por idioma.
- Persistencia de datos PostgreSQL.

### Tecnologías utilizadas:
- Java 17
- Spring Boot 3.2.3
- Maven
- PostgreSQL
- Jackson
- HttpClient
- JPA / Hibernate

### Requisitos previos:
- Java JDK 17+
- Maven 4+
- PostgreSQL 16+
